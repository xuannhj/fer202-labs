### **Lab 2 - React Hooks**

#### **Instructions**

In this assignment you will add some React Hooks to the React application. Using your Lab 1 for continuing this Lab.

#### **Objectives and Outcomes**

In this assignment, you will continue to work with the React application that you have been developing in the Lab1. You will add some React Hooks for showing the detail information of a orchid, toggle to the dark and light theme for all elements at your React application. At the end of this assignment, you should have completed the following tasks:

- Created a modal to show the information orchid when you click to Detail button into your React application.
- Toggle the theme mode.
- At lease initialize a custom hook for your React application.

**Assignment Requirements**

- All the images put in a folder or using the URL.
- The data stores in ListOfOrchids.js file.
- Using React Hooks including Custom Hook.
