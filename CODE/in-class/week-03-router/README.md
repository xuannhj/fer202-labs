# 🧭 Week 3: React Router & Quản Lý Sản Phẩm

> **Sinh viên:** Nguyễn Phạm Xuân Nhi — **MSSV:** SE201170

Dự án thực hành **Tuần 3**, tìm hiểu và áp dụng thư viện **`react-router-dom`** để điều hướng đa trang (Single Page Application - SPA).

---

## 🎯 Mục Tiêu Bài Học
- Cài đặt và cấu hình `<BrowserRouter>`, `<Routes>`, `<Route>`.
- Xây dựng thanh điều hướng `<MyNavBar>` với `<Link>` và `<NavLink>`.
- Quản lý danh sách sản phẩm, hiển thị chi tiết sản phẩm và trang 404 (NotFound).

---

## 🚀 Hướng Dẫn Chạy Dự Án
```bash
# Cài đặt thư viện
npm install

# Chạy server phát triển
npm run dev
```
